# きっずふぁむ 領収書アプリ

スマホ（Android）で領収書を撮影すると、AIが内容を読み取り、確認後に Google ドライブへ自動で整理・集計するアプリです。

- 撮影 → **自動トリミング**（四隅を指で調整できます）→ **AI読み取り** → 「この内容で合っていますか？」→ **OK** で保存
- 保存先：`きっずふぁむ　領収書 / 2026年度 / 07_10月 / 2026-10-02_レッスン室_大槌町文化交流センター_1000円.jpg`
- 年度（4月〜3月）のスプレッドシート `2026年度_経費一覧` に自動で追記（月ごとのシート＋年間集計）
- **二重登録の警告**（番号が同じ／支払日・支払先・金額が同じ）
- **電波がなくても撮影OK**：端末に保存し、つながったら自動送信
- **Googleカレンダー照合**：「SARA」の予定（おしゃっち・大槌／TETTO・釜石）に領収書があるか確認
- 種類：レッスン室・交通費・駐車場代・備品代・その他（レシートも可）

## 構成

| フォルダ | 中身 |
|---|---|
| `docs/` | スマホで開くアプリ（GitHub Pages で公開） |
| `gas/` | Google Apps Script（保存・集計・AI読み取り・カレンダー照合） |

APIキーや合言葉はリポジトリには入れません（GAS のスクリプトプロパティとスマホ内にだけ保存）。

## セットアップ手順

### ① Google Apps Script を作る（kids.peace.official@gmail.com でログイン）

1. https://script.google.com を開き「新しいプロジェクト」→ 名前を `きっずふぁむ領収書` に変更
2. 左の ⚙️「プロジェクトの設定」→「“appsscript.json” マニフェスト ファイルをエディタで表示する」に✅
3. 左の「エディタ」に戻り、
   - `appsscript.json` の中身を、このリポジトリの [`gas/appsscript.json`](gas/appsscript.json) に置き換え
   - `コード.gs` の中身を [`gas/Code.gs`](gas/Code.gs) に置き換え → 💾 保存
4. ⚙️「プロジェクトの設定」→ 下の「スクリプト プロパティ」→「プロパティを追加」
   - プロパティ：`CLAUDE_API_KEY`　値：Claude APIキー（`sk-ant-…`）
5. エディタ上部の関数で `setup` を選び ▶「実行」→ 権限の確認 →「詳細」→「（安全ではないページ）に移動」→「許可」
   - 実行ログに **合言葉（APP_TOKEN）** が表示されます（スクリプトプロパティにも保存されています）
6. 右上「デプロイ」→「新しいデプロイ」→ 種類 ⚙️「ウェブアプリ」
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
   - 「デプロイ」→ 表示される **ウェブアプリのURL**（`https://script.google.com/macros/s/…/exec`）をコピー

> コードを更新したときは「デプロイ」→「デプロイを管理」→ ✏️ →「バージョン：新バージョン」→「デプロイ」で、URLを変えずに更新できます。

### ② アプリを公開する（GitHub Pages）

無料プランの GitHub Pages は **公開（Public）リポジトリ** で使えます。このリポジトリには秘密の情報は入っていないので、公開にしても大丈夫です。

1. GitHub のリポジトリ →「Settings」→「General」の一番下「Change visibility」→ **Public**
2. 「Settings」→「Pages」→ Source：**Deploy from a branch** → Branch：**main** / **/docs** →「Save」
3. 数分後に `https://tamayurazoku.github.io/kidsfam-receipt/` で開けるようになります

### ③ スマホにインストールする（Android / Chrome）

1. Chrome で次のURLを開きます（`GASのURL` と `合言葉` を置き換え）
   ```
   https://tamayurazoku.github.io/kidsfam-receipt/#gas=GASのURL&token=合言葉
   ```
   ※ 普通に開いて「設定」画面に手入力してもOKです
2. 「✅ 接続できました」と出ればOK
3. Chrome のメニュー（︙）→「アプリをインストール」（または設定画面の「📲 アプリとしてインストール」）
4. ホーム画面のアイコンから起動 → カメラの使用を「許可」

## 使い方

1. アプリを起動するとカメラが立ち上がります → 撮影
2. 切り抜き範囲を確認（自動で検出。ずれていたら ● を指で動かす）→「この範囲でOK」
3. AIが読み取った内容を確認・修正 →「OK（保存）」
4. 同じ領収書が登録済みのときは警告が出ます（「保存しない」／「それでも保存」）
5. 電波がないときは「あとで読み取る」→ 電波が戻ると自動でAIが読み取り、「送信待ち」タブに確認依頼が出ます

### ルール
- 日付は **支払日**（西暦）で統一。フォルダ・ファイル名・集計すべて支払日基準
- 年度は 4月〜3月（例：2027年2月の支払い → 2026年度）
- 施設利用許可書（釜石市民ホール）は領収書として扱い、「決済」日を支払日にします
- 「利用者登録番号」は毎回同じなので、二重登録の判定には「申請受付番号」や領収書No.を使います

### 税理士さんへの提出
年度フォルダの `XXXX年度_経費一覧` スプレッドシートを共有してください。Excel が必要な場合は「ファイル」→「ダウンロード」→「Microsoft Excel」。
